      The Feature Layer
      Feature modules are the functionality of the website such as navigation, search, content, accounts, etc. The bulk of the business logic and presentation elements sits in these modules.

      Accounts

      The accounts module handles user accounts and user profiles including login, registration, forgot password and profile editing.

      Read more

      Demo

      The Demo module contains a number of features used for demonstrating aspects of the Sitecore platform, such as triggering a campaign from external sites or  information about what the Sitecore Experience Database contains.

      Read more

      FAQ

      The FAQ module features a handy accordion control to show questions and answers.

      Read more

      Identity

      The corporate or organisational identity of the website is managed by the Identity module. This includes Logos and legal footer information.

      Read more

      Language

      The language module contains functionality related to the multi-language support of Habitat.

      Read more

      Maps

      The Maps module allows you to add maps with points to the pages of your website.

      Read more

      Media

      The Media module contains functionality for Carousels, Lightboxes and Videos.

      Read more

      Metadata

      The metadata module covers functionality related to HTML and SEO metadata.

      Read more

      Navigation

      All menus and navigation components reside in the Navigation module.

      Read more

      News

      The News module contains news functionality including lists, articles and teasers.

      Read more

      Page Content

      Page Content contains the functionality and content for basic article style pages, including page title, body text etc.

      Read more

      Person

      The Person module contains person-related functionality and content, e.g. employee pages, personal contact info and quotes.

      Search
